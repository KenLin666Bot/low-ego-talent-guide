### 核心内容框架
1. **先定标尺**：真假 Low Ego 的核心分水岭（Being Right vs. Getting It Right）
2. **招聘四步法**：复盘深挖（I vs We / 败仗复盘）、现场压力反驳实测、反向提问、3道背调必问
3. **入职四阶段**：试用融入期（0–3个月）、日常深水协作（报喜 vs 报忧）、事故复盘期、带队管理期（360剪刀差识别）
4. **防偏三边界**：看冷却后动作、区分文化习惯、保护锐气避免平庸组织
